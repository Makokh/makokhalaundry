# MakokhaLaundry

A responsive one-page website for MakokhaLaundry, serving Eldoret, Kenya.

## Business details
- WhatsApp: 0758 545 896 (+254758545896)
- Wash & Fold: from KSh 70 per kg (starting from 1 kg)
- Duvet cleaning: KSh 600 per duvet
- Ironing and delicate-care prices: contact for a quote

## Features
- Services and price sections
- Booking form that opens WhatsApp with the customer's request
- Mobile-friendly layout

## Note
This is a front-end website. The booking form sends a message through WhatsApp; it does not store orders in a database or accept online payments.
